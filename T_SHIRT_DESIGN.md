## 🏭 Techniques d'Impression

### 1. Sérigraphie (Recommandé)
- **Avantages** :
  - Durable (résiste aux lavages)
  - Couleurs vives
  - Coût faible pour quantité
- **Inconvénients** :
  - Minimum 50-100 pièces
  - Temps de setup

### 2. Flocage/Vinyl
- **Avantages** :
  - Qualité premium
  - Pas de minimum
  - Très durable
- **Inconvénients** :
  - Plus cher
  - Sensation différente au toucher

### 3. Broderie
- **Avantages** :
  - Très haut de gamme
  - Extrêmement durable
  - Effet premium
- **Inconvénients** :
  - Très cher
  - Limité aux logos simples

### 4. DTG (Direct to Garment)
- **Avantages** :
  - Pas de minimum
  - Détails fins possibles
  - Couleurs multiples
- **Inconvénients** :
  - Moins durable
  - Plus cher par pièce

## 📱 Intégration QR Code

### Avantages du QR Code sur T-shirt
- **Interactivité** : Scan direct vers l'app
- **Mémoire** : Les gens gardent le t-shirt
- **Viralité** : Curiosité générée
- **Trackabilité** : Mesurer les scans

### Positionnement QR Code
- **Sous le logo principal** : 3-4cm d'espacement
- **Côté gauche/centre** : Éviter le côté droit (poche)
- **Taille** : 4x4cm minimum pour scan facile

### URL QR Code
```
https://sentreso.com/download
ou
https://apps.apple.com/app/sentreso-finance
```

## 💡 Conseils Pro

### Design
- **Simplicité** : Moins c'est plus
- **Lisibilité** : Test à 2m de distance
- **Durabilité** : Design qui résiste aux lavages
- **Polyvalence** : S'adapte à tous les styles

### Distribution
- **Timing** : Distribuer aux bons moments
- **Message** : Préparer pitch court
- **Suivi** : Garder contact avec bénéficiaires
- **Feedback** : Collecter retours pour améliorer

### Budget
- **Phase test** : Commencer petit (50 pièces)
- **Qualité** : Ne pas lésiner sur la qualité
- **Négociation** : Prix de gros dès 100 pièces
- **Stock** : Prévoir marge de sécurité
